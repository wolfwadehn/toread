Folders Src

The source code of Flux is organized into the following folder structure:

X:\
├── Src\          C# source code (single solution: Flux.sln)
│   ├── Base\     Foundation: geometry, mesh, polylines, IO primitives, rendering layer (Lux)
│   ├── Core\     "Engine": domain models + their views (VModel hierarchy)
│   ├── UI\       Controllers (Glob hierarchy) + WPF dialogs
│   ├── App\      Main window, tabs, shell — this is what gets compiled into Flux.exe
│   ├── API\      Narrow wrapper for 3rd-party automation
│   ├── Console\  Developer CLI (metadata rebuild and other utilities)
│   ├── Migrate\  CLI migration from MetaCAM / TOPS legacy data
│   ├── Hula\     C++/CLI wrapper around HOOPS (3D import) — built separately
│   ├── Lib\      External NuPkgs / DLLs (Aegis, Trumpf-Licensing, ...)
│   ├── Publish\  Publish profiles / setup scripts
│   ├── bin\      Build output (all DLLs end up here)
│   └── obj\      Intermediate output
├── Test\         Test project (Flux.Test.csproj — framework is "Flit")
├── TData\        Test input data (.geo, .vdwg, ...) organized by domain
├── Data\         Runtime data: machines, tools, materials
├── Doc\          Images and concept diagrams (with a `.png` gallery per domain)
├── Help\         End-user manual (FTex)
├── Notes\        DEVELOPER notes (FTex) — see §8, well worth reading
├── Resources\    Fonts, HOOPS binaries, icons
├── Tools\        Helper utilities
├── Wad\          Read-only resources packed into Flux.wad
├── SDK\          SDK artifacts for API consumers
└── .github\      CI/CD
