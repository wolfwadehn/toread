Glossary

Glossary

Term Meaning
Deposit site The table, pallet, or container onto which an unloader places a cut part.
Deposit Editor MetaCAM's existing tool for editing deposit locations across a Schedule of layouts (the direct ancestor of this module).
Schedule A MetaCAM collection of layouts (with per-layout Sheet Count) that can be edited for deposit locations collectively.
Sheet Count Number of physical sheet repeats of a layout; determines how many part copies must be piled.
Stacking Thickness A per-part override (Custom Settings) for piling height, used instead of raw sheet thickness (e.g. for parts with forming).
Pile / Stack An ordered group of identical parts deposited on top of each other at one X/Y location.
Automation type The physical unloading mechanism: gripper-based unloader (e.g. AK08, AK09), SheetMaster, SortMaster (pallet or box/linear), conveyor/robot cell (KB40, CS05), or manual removal.
Gripper The end-effector that lifts a part off the sheet/skeleton; has geometry, reach envelope, and may be excentric (offset from the machine axis).
Pallet A physical, standardized (or custom) load carrier with defined footprint, margins, and max stack height/weight.
Reachable zone / Non-reachable zone The region of a pallet that the (fixed-position) gripper/robot can physically access, given cart position, gripper offset, and current stack height.
Backward planning Praxis' planning direction: define the job in downstream-to-upstream order (e.g. Bending, then Cutting) so upstream steps inherit constraints from downstream ones.
Reference corner The pallet corner used as the coordinate origin for stack placement (mirrors "Reference corner" in the Praxis Palletizing ribbon).
Stacking mode The deposit strategy for a pile, e.g. "Regular dropping" (seen in the Stack data dialog).
LST / Setup plan / Einrichteplan The TRUMPF/MetaCAM ASCII table export (BEGIN_*/ENDE_* blocks) carrying machine, sheet, cutting-technology, part, and NC-program data for a job. See chapter 07.
Unload Sequence / Unload Name / Pallet Name / Reference Part Fields already reserved (but blank in a plain cutting job) in the LST's BEGIN_PARTS_IN_PROGRAM_POS table; this module is the primary producer of their values.
Flux Cut The nesting/cutting job application (.fx single-part files, .fxjob job/nest container) that produces the LST this module imports.
