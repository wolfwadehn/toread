ARVValueLegendsconsolidated

product: trukit org: trumpf title: "ARV Value Legends (consolidated)" tags: [trukit, truarv, arv, bend, reference] status: reverse-engineered-draft related: ["[[ARV Format & Value Mapping]]", "[[TruARV]]"]

ARV Value Legends (consolidated)

Master list of the coded ARV attributes (the attribnameN / attribvalueN pairs inside .arv entries) and what each integer value means, grouped by attribute. It aggregates every value legend the per-cluster analyst notes produced (Suction & Grippers, Magnets & Removal Stations, Upper Tools / Punches, Dies & Special Bend Tools, Holders/Adapters/Seats & Lists, Bend Factors & Materials) and reconciles them with the legends already shipped in the TruARV tool (packages/core/src/infotexts.ts, the INFO_TEXTS map migrated from the legacy TruNinja Resources.resx).

Each attribute is tagged EXISTING (already in INFO_TEXTS) or NEW (recovered here, extends the tool). The [[#Portable snippet]] at the bottom gives the NEW high/medium-confidence legends ready to paste into infotexts.ts; the [[#Undetermined]] list gathers coded columns whose legend could not be recovered from the schema-only snapshot.

[!warning] Two enum universes — do not mix All numeric legends here are the ToPs 600 / ARV enums (authoritative for .arv files). Where a same-named enum exists in the legacy tc_dbase C headers (benddef.h Biegeart / Biegemethode / Biegetechnik, TcSauger.h, steu_def.h) the numbering is different and is cross-reference only — those rows are labelled (code-crossref) and must never be applied to ARV values.

[!note] Scope caveat The source SQL is a schema-only dump: ENUMWERTE/catalog tables carry no seed rows. So catalog-backed columns (materials, seats, finishing, die/shape enums) have a known meaning but an unrecoverable numeric legend — those live in [[#Undetermined]], not below.

Ordered by theme: tool-class enums → install/position flags → yes/no & boolean flags → automation/gripping → materials & bend factors. Attributes reported by more than one cluster are merged into a single entry with all owning tables listed.

Undetermined

Coded attributes whose numeric legend could not be recovered from the schema-only snapshot (labels/meanings may be known, but codes need an ENUMWERTE / catalog data dump, or a SPRACHEN_ENG text join). Do not guess these into the tool.

Catalog-backed IDs (ENUMWERTE seed rows missing):

  • WerkstoffID — tool/material catalog. Defaults: SAUGERPLATTE 2, MULTIGREIFER 1, holders 1.
  • MaschinenTypID — machine-type catalog (holder/adapter default 2).
  • EndbearbeitungID — finishing type (Art der Endbearbeitung); separate enum from BeschreibungID despite numeric overlap. Defaults: Halter 52, Adapter 51.
  • Eignung — suitability (WZG_SAUGERPLATTE/MULTIGREIFER/GREIFZANGE default 3; holders default 0).
  • Separierungstyp — separation/singulation type (default 1).

Die / tool shape enums (meaning known, numbers unknown; defaults fall outside the resx MatritzenformID 58–71 / StempelformID 54–57 ranges):

  • GesenkformID (WZG_GESENK, default 21) — V/U/round die shape.
  • GesenkartID (WZG_GESENK, default 28) — extra bend right/left.
  • FlachBearbID (WZG_FLACH, default 24) — flat machining type (coining/joining/forming; benddef.h Biegetechnik 10/11/12 is cross-ref only).
  • WellenformID (WZG_WELLE, default 36) — shaft form (round/conical).
  • MessformID (WZG_TASTSCHEIBEN, default 34) — measuring-disk form (round/linear).

Gripping / automation codes (categories known, numeric mapping not):

  • Aufgaben (WZG_SAUGER, default 1) and SaugerInnen_Aufgabe / SaugerAussen_Aufgabe (WZG_MULTIGREIFER_ARM, default 0) — task/functionality. Arm default 0 vs. cup default 1 suggests different encodings, possibly a bitmask on the arm (combined "WägenVereinzeln" value).
  • Backentyp (WZG_GREIFPRATZE, default 1) — jaw type; index misnamed $BeschreibungID hints a shared family (unverified).
  • BeschreibungID on WZG_GREIFZANGE (default 1) — tong tool-type number; the 38–51 punch/die legend does not apply.
  • Klasse (WZG_AUSLEGER, default 0) — cantilever-type id.
  • Pratzenlage (WZG_PRATZENPOSITION, default 0) — encodes upper/lower and left/right jaw; parallels LageID conceptually but a different code space.

Flags bounded but unlabelled:

  • WerkzeugwechslerFlag beyond 0 — CHECK-bounded 0–3, per-value meanings undocumented (0 presumed "not suitable").
  • EinbauSafetyClickID is resolved (0–3 above); listed here only for the WZG_HALTER CHECK note — no action needed.
  • WZG_MA_GRUPPE.WZG_MA_BIEGEART (default 0) — 0-based vs. reuse of ARV Biegeart 1/2/3 unresolved.
  • WZG_ENTNAHMESTATION.TeilanschlagInXRichtung / TeilanschlagInYRichtung — coded ints, likely direction/enable flags, no legend.
  • WZG_TABELLEN visibility flags OW_COMBOBOX / UW_COMBOBOX / OW_KATALOG / UW_KATALOG / WERKZEUGFILTER — no MS_Description; presumed 0/1 but unverified.

Materials / misc:

  • *_LOCKSTATE non-zero reason codes — stored in CONST_TRANSLAT_CUSTOMER (customer-specific).
  • WS_BEM_LINK, WS_PCS_FORMEL — FK/id references (into TEXTE and a formula table); value ranges not enumerable.
  • table:WZG_TYP — appears in ARV archives but has no DDL in this snapshot (EXPORT_CLASSNAME_TABLE_MAP seedless); likely the tool-type master keyed by the WZG_TYP_ID 16–26 enum, unverified.
