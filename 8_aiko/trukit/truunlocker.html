TruUnlocker

Part of [[TruKit]]. Clears common Windows corporate policy locks in one go. (Ported from TruKitV4's Unlocker.)

What it does

Select which locks to clear, then Unlock selected. Everything runs in a single elevated PowerShell pass, so you get one Windows administrator (UAC) prompt; results show which items succeeded or failed. The available actions include:

  • Unlock Google Chrome policies.
  • Unlock Microsoft Edge policies (and separately, allow all Edge extensions).
  • Allow development without a developer license.
  • Allow the winget default source.
  • Show the "New Outlook" toggle in classic Outlook.

Clearing a policy that isn't set counts as success (already unlocked). When something fails, the exact reason is shown and the last run is written to a log (%TEMP%\trukit-unlocker-last.log) you can send for support.

Availability

local-backend, Windows-only — needs the desktop app on a Windows host. The actual registry / PowerShell actions are hard-coded in the app (the UI only sends back which ones you selected), so only vetted changes can run.
