product: trutopscad org: trumpf title: "Domain Model & Glossary" doc: "04 - Domain Model & Glossary" id-prefix: "-" srs-standard: "ISO/IEC/IEEE 29148:2018" status: reverse-engineered-draft source: "TruTopsCAD legacy source snapshot (files dated May 2024)" related: ["[[00 - Index & Reading Guide]]", "[[03 - System Context & Architecture Overview]]", "[[10 - FR - CAD Geometry & Drawing Editing]]", "[[12 - FR - Part & Data Management]]", "[[19 - FR - Tools, Machines, Materials & Technology]]", "[[60 - Requirements Traceability Index]]"] tags: [requirements, trutops, glossary]

Domain Model & Glossary

This document defines the shared ubiquitous language of the reverse-engineered TruTops CAD/CAM suite: the core business/engineering entities, how they relate, and a consolidated glossary. It is the vocabulary reference for every functional-area SRS ([[10 - FR - CAD Geometry & Drawing Editing]] through [[23 - FR - Automation, Scripting & Integration]]) and should be read alongside [[03 - System Context & Architecture Overview]]. Domain terms are German in the source; each is given with its German original and an English definition in Section 3.

The model was recovered by static analysis of the C/C++ modules (tc_dbase, tc_cad, tc_stz, tc_las, tc_rohr, tc_nest, ...), the GRIT .gritx masks, and the Databases/ SQL Server schema (510 table definitions across the Common, Punch, Laser, Bend, Nest, Tube, CAD, Text and DATADICT schemas, each with a parallel _inch variant).

1. Core Domain Entities & Relationships

The domain divides into three loosely coupled clusters:

  1. Geometry / CAD — the in-memory drawing model (Drawing → Part → Contour → Element → Point) plus annotations, bends and per-element technology. Persisted as native geometry files (GEO/MI/TAF). Owned by [[10 - FR - CAD Geometry & Drawing Editing]] and [[12 - FR - Part & Data Management]].
  2. Master data / Technology — machines, tools, materials and technology tables held in the relational database. Owned by [[19 - FR - Tools, Machines, Materials & Technology]].
  3. Production / Planning — orders, nesting jobs, nested sheets, programming projects, NC programs and production plans. Owned by [[17 - FR - Nesting & Palletizing]], [[18 - FR - NC Generation & Motion Optimization]] and [[20 - FR - Production Planning & Projects]].

1.2 Entity descriptions

Geometry / CAD cluster (see [[10 - FR - CAD Geometry & Drawing Editing]])

  • Drawing (Zeichnung, S_draw) — the top-level 2D geometry document and the unit saved to a geometry file. Contains parts, contours, elements, dimensions and variants. Confirmed as struct S_draw in tc_dbase.
  • Part (Teil / Einzelteil, S_teil) — a logically grouped set of contours/elements within a drawing; carries a transformation matrix and an identity/text-info number. A sheet drawing (nest) contains many parts; a single fabricated item is an Einzelteil.
  • Contour (Kontur, S_kontur) — an ordered, connected chain of geometry elements; open or closed, outer or inner (an inner contour = a hole/island usable for [[17 - FR - Nesting & Palletizing]] part-in-part).
  • Geometry element (Element, S_element) — the atomic geometry unit: line, arc, circle, point, text, spline or bend line, each with colour and line-style attributes (there is no named-layer object; DXF layers are mapped to colour/line-style on import — see [[11 - FR - Import, Export & File Formats]]).
  • Point (Punkt) — a coordinate node: element endpoint, catch/snap point or construction point.
  • Dimension (Bemassung) — a linear, angular, radial, diameter, arc-length or ordinate annotation with text and tolerance.
  • Variant (Variante) — a parametric definition (variables, references, changes, loops) driving geometry variation, evaluated via the embedded Python interpreter (see [[23 - FR - Automation, Scripting & Integration]]).
  • Technology (Bearbeitung) — the machining assigned to a geometry element/contour (punch hit, cut, mark, notch, forming). The join between geometry and the technology domain; typed by E_tb_art. Consumed by [[18 - FR - NC Generation & Motion Optimization]].
  • Micro-joint (Mikrosteg / Steg) — a small uncut bridge keeping a cut part attached to the skeleton until removal.
  • Bend (Biegung) — a single fold on a part carrying kind (Biegeart), method (Biegemethode), technique (Biegetechnik), angle, radii, deduction factor and assigned upper/lower tools. Owned by [[16 - FR - Bending (ToPs 600)]].

Master-data / Technology cluster (see [[19 - FR - Tools, Machines, Materials & Technology]])

  • Material (Werkstoff, MAT_MATERIAL) — a material grade with physical/technological properties (tensile strength, specific weight, E-modulus, thermal conductivity, hardness) and international designations (DIN/EN/ASTM/JIS). Keyed by WS_ID.
  • Raw material (Rohmaterial, MAT_RAWMATERIAL) — a material + thickness variant (keyed by RM_NAME), adding foil/coating, tool-clearance and load tolerances.
  • Sheet / stock (Tafel / Lagergut, MAT_SHEET) — a concrete storable sheet (or remnant) of a raw material with X/Y dimensions, quantity, storage location and a geometry-file reference; lockable (MAT_LOCKSTATE) when consumed by an order.
  • Material group (Werkstoffgruppe, MAT_GRP) — a grouping of materials with abbreviation and price-per-kg for costing.
  • Machine (Maschine, MASCHINE) — a machine type identified by a 4-part machine key (MA_NAME, MA_TYP, MA_STEUERUNG, MA_ST_VERSION); carries work area, traverse/overrun area, sheet capacity, per-axis dynamics and peripheral equipment.
  • Controller (Steuerung) — the machine control (e.g. Siemens SIN840D) with a version; part of the machine key and the lookup key for NC cycles/formats and control-version gating (STEUERUNGSVERSIONEN).
  • Tool (Werkzeug) — a punch/laser/die element machining the sheet. Punch tools are stored in WZG3_DATEN with a rich type taxonomy (single tool, multi-tool, thread former); dies in DIE/LASERMATRIZE; bend tools in the Bend.WZG_* family.
  • Ruleset (Regelwerk) — machine/technology rules governing automatic assignment. Two flavours: the key/value system configuration (REGEL_ALLG, per technology schema) and the punch/laser assignment rules (STANZ_REGELN, REGEL10..201).
  • Laser technology table (Lasertechnologietabelle, LTT, LASERTECHNO) — a machine-/material-/thickness-dependent cutting, piercing and marking parameter set, with small/medium/large contour-size and normal/reduced variants.
  • Tube technology (TUBETECH) and profile (PROFILTAB / Profil) — the tube cross-section catalogue and the master record binding cross-section + material + dimensions to a technology dataset. Owned by [[15 - FR - Tube & Profile Machining (ToPs 400)]].
  • Bend factor (Abkantfaktor, AKF_BENDFACTORS) — the bend-deduction/allowance factor for flat-length calculation, keyed by material, thickness, tool group, angle and radius. Sourced from the ToPs 600 bend database.

Production / Planning cluster (see [[17 - FR - Nesting & Palletizing]], [[18 - FR - NC Generation & Motion Optimization]], [[20 - FR - Production Planning & Projects]])

  • Order (Auftrag) — a production order grouping parts with target/min/max quantities and priorities; order parts are captured in TEILE_ERFASSEN (each row = a part with quantities, rotation/mirror, grain constraint, GTS-suitability, due date TEIL_TERMIN).
  • Nesting job (Schachtelauftrag) — parts + raw sheets + parameters submitted to the nester; its result is the set of nested sheets.
  • Nest result / result sheet (Ergebnistafel, Tafel) — a single nested-sheet layout (*.taf) with placed parts, clamps and dead zones; the sheet-format variant is TAFEL_VARIANT (dimensions + material + optional stock link).
  • Programming project (Programmierprojekt / PPJ / Arbeitsmappe) — a versioned XML .ppj workbook binding one order to a machine, material, sheets (Rohling) and parts. The organisational hub of [[20 - FR - Production Planning & Projects]].
  • NC program & production plan (Fertigungsauftrag / Produktionsplan) — the controller-specific NC output generated per sheet, and the sequenced set of NC programs (the NcListe) assembled and formatted by the external NcLink tool for the machine control.

2. Persistent Data Model Notes

Evidence from Databases/SQLServerDatabase (510 table definitions). See [[12 - FR - Part & Data Management]] for the persistence requirements and [[30 - External Interface Requirements]] for the ODBC/PDM interfaces.

2.1 Two storage worlds

TruTops persists across two distinct stores:

  • Native geometry files — GEO/GEO_102/MI/TAF/GMT text files holding the Drawing → Part → Contour → Element model, accessed transparently over the local file system or a PDM/TRUMPF.NET vault via the OmAdapter facade. The in-memory structs (S_draw, S_teil, S_kontur, S_element) were confirmed in tc_dbase.
  • Relational database — SQL Server (or a locally attached Access/MDF) reached over ODBC, holding all technology, master data, order/stock inventory, the system rule set and multilingual text.

2.2 Schema organisation

Tables are grouped into technology schemas — Common, Punch, Laser, Bend, Nest, Tube, CAD, Text, DATADICT — each mirrored by a parallel _inch schema (120 _inch. table files observed), giving the metric/inch database duality. Cross-technology master data lives in Common (materials, sheets, bend factors, rule set, text); per-technology tables (e.g. Punch.STANZ_REGELN, Laser.LASERTECHNO, Tube.TUBETECH) sit in their own schema.

2.4 Cross-cutting governance columns

Master records widely carry *_VISIBLE (soft-hide), *_LOCKSTATE / *_GESPERRT (read-only / in-use locking) and *_TRUMPF_FLAG (TRUMPF-supplied vs. customer data) columns. The exact semantics of the governance flags and of multi-user concurrency (SQL engine vs. lock flags vs. PDM check-out) were not fully resolved — see the open questions in [[12 - FR - Part & Data Management]].

3. Glossary

Consolidated, de-duplicated and alphabetised from all functional-area documents plus terms derived from the Databases/ SQL. The German column gives the source-language original; where a term is inherently English (e.g. AutoCut, GTS, LTT) the German column repeats it or notes the German equivalent.

Term German Definition
Abbuchen (stock deduction) Abbuchen Booking consumed sheets/remnants off the material stock inventory.
Abfall (scrap) Abfall Waste material to be disposed of via palletizing or ejection.
Abfallzerschnitt (scrap dicing) Abfallzerschnitt Cutting the residual skeleton into small removable pieces. See [[14 - FR - Laser Cutting (ToPs 100)]].
Abkantfaktor (bend-deduction factor) Abkantfaktor Correction factor for flat-length calculation across a bend; looked up from the ToPs 600 AKF_BENDFACTORS table by material, thickness, tool group, angle and radius.
Abdampfen (de-foiling) Abdampfen A laser step that vaporizes/burns off protective foil before cutting.
Abwicklung (unfolding / flat pattern) Abwicklung The flat 2D development of a bent part, profile or tube surface; opposite of the folded/3D representation.
Abstapeln (unstacking) Abstapeln Removing/placing parts from the sheet onto a stack during palletizing.
Abstreifen (scrap stripping) Abstreifen Machine operation removing scrap/skeleton after processing.
Aequidistante (equidistant / offset) Aequidistante Offset contour generated at a fixed distance from a source contour, on a chosen side.
Anfahren / Wegfahren (lead-in / lead-out) Anfahren / Wegfahren Approach/retract path added before/after a cut contour so the pierce lies off the finished edge.
Anlegen (apply cutting edge) Anlegen Applying a tool cutting edge along an element/contour (single-hit, full-nibble, partial-nibble or single-hit-at-two-elements mode).
Anschnitt / Anfahrfahne (lead-in) Anschnitt / Anfahrfahne The approach-cut segment; considered in part spacing during nesting.
AppState (application state) App-Zustand A named checkable UI state exposed by tc_guiAdapter to synchronise legacy GRIT dialogs with the Qt GUI. See [[22 - FR - UI Framework, Dialogs & Interaction (GRIT)]].
Arbeitsbereich (working area) Arbeitsbereich A machine's addressable processing extents.
Arbeitsmappe (workbook) Arbeitsmappe In-memory/XML representation of a programming project (class TcArbeitsMappe).
ASM (application state machine) Anwendungs-Zustandsautomat A yacc/lex command interpreter that parses command strings and executes state transitions; driven interactively and via scripted asmCall(). See [[23 - FR - Automation, Scripting & Integration]].
Aufsetzen / Aufsatz (mount) Aufsetzen Tube machining case where a tube sits on/against another surface.
Aufspannung (setup / clamping) Aufspannung One sheet position between repositioning moves.
Auflager (support) Auflager Fixed/movable rest supporting the tube on the machine bed.
Auftrag (order) Auftrag A production order grouping parts with target/min/max quantities and priorities; the key of a programming project.
Ausnutzung (utilization) Ausnutzung Fraction of sheet area occupied by usable parts after nesting.
Ausschleusen (ejection / discharge) Ausschleusen Removing finished parts/scrap via ejector, flap/chute, suction, lift or gripper.
Ausduennen (thinning) Ausduennen Reduction of element/point density during conversion (rough/middle/fine levels). See [[11 - FR - Import, Export & File Formats]].
AutoCut / Gemeinsames Trennen (common cutting) AutoCut / Gemeinsames Trennen The shared automatic-processing engine (tec_acut) and, in nesting/punch, one separating cut shared by two adjacent parts, driven by named configurations.
Auto-TMT Auto-TMT Automatically generated TMT created for a sheet lacking one by adopting machining from the part overview.
Bahnkorrektur / Kreiskorrektur (kerf / circle correction) Bahnkorrektur / Kreiskorrektur Kerf/path compensation of the tool path (and dedicated circle correction for holes) to reach nominal dimensions.
Bearbeitung (machining operation) Bearbeitung A single technology operation applied to geometry (punch hit, cut, mark, notch); the join between geometry and technology, typed by E_tb_art.
Bearbeitungsmuster (processing pattern) Bearbeitungsmuster A stored parametric processing reusable on matching geometry (BEARBMUSTER, muster.gritx).
Bearbeitungszeit / Wegzeit (cycle time) Bearbeitungszeit / Wegzeit Estimated machine movement time computed from jerk-limited acceleration ramps for linear and circular segments.
Belegung (sheet layout / occupancy) Belegung Sheet layout/occupancy context; one of the view-settings contexts (c_beleg).
Beladestrategie (loading strategy) Beladestrategie Algorithm computing a sheet's loading position on the machine (fixed, centered, at grip/clamp, from table, SheetMaster-Compact).
Bemassung (dimensioning) Bemassung Linear, angular, radial, diameter, arc-length or ordinate annotation with text and tolerance.
Beschriftungstext / Signieren (marking text) Beschriftungstext / Signieren Marking/scribe text applied by punch or marking tools.
Besaeumen (trimming) Besäumen Cutting the outer sheet edges to the required format.
Biegeart (bend kind) Biegeart Bend classification: normal bend, hemming, wave, conical, flat, Z-bend, die-bend, double, swivel or auxiliary.
Biegemethode (bend method) Biegemethode Forming method: air bending (Freibiegen), coining (Prägen), seam-with-gap, closing (Zudrücken) or swivel bending.
Biegetechnik (bend technique) Biegetechnik Execution technique: normal, pre/post, bumping, U/V/round die, coining, joining or forming.
Biegewerkzeugassistent (bend tool assistant) Biegewerkzeugassistent A wizard for creating/editing standard bend-tool geometry (punch, die, Z-tool, adapter).
Blechdicke (sheet thickness) Blechdicke Sheet/material thickness; combined with a material to form a raw material.
Blechfabrik (sheet-metal factory) Blechfabrik The sheet-metal factory workflow where the GMT drawing number is the through-going part identifier.
Blechvermessung (sheet measurement) Blechvermessung Probing the actual sheet position/edges before cutting to compensate loading inaccuracy.
Bombieren (ram crowning) Bombieren Ram-crowning compensation for press-brake deflection; values held in the ToPs 600 database (BOMBWERTE).
Bruecke (bridge, guiding element) Brücke A guiding element (Tubematic) supporting the tube during machining.
Bumping Bumping A rounded/large-radius bend realised as several parallel small bends formed together.
CAPT CAPT An MI import mode that also converts punch single-stroke (Einzelhub) technology into Dbase attributes.
Constrained TSP Constrained TSP Travelling-Salesman-style sequencing over a dependency graph, solved with nearest-neighbour + Ant-Colony + post-optimization heuristics. See [[18 - FR - NC Generation & Motion Optimization]].
DATADICT (data dictionary) Datenverzeichnis The data-dictionary schema whose rows define tables/columns/relations/indexes and whose triggers auto-create the physical tables per technology schema.
Darstellung (display / rendering) Darstellung Display/rendering of geometry on a device. See [[21 - FR - Visualization, Viewing & Plotting]].
Dehnen (stretch) Dehnen Moving a defining point to resize connected geometry.
dialog_neu dialog neu MMK command that clears/rebuilds a dialog (e.g. before repopulating a finder list).
Dongle / Wibu (licensing) Dongle / Wibu Hardware/software licence protecting each edition and each import/export format.
Doppelwagen (double wagon) Doppelwagen Dual disposal-wagon configuration in palletizing.
Drawing Zeichnung (S_draw) Top-level 2D geometry document containing parts, contours, elements, dimensions and variants; the unit saved to a geometry file.
Drehbarkeit (rotatability) Drehbarkeit Constraint on how a part may be rotated when nesting: not rotatable, freely, 90°, 180°, or grain-direction.
DSTV Deutscher Stahlbau-Verband German steel-construction NC standard; only its 2D geometry is imported.
Durchdringung (penetration) Durchdringung Intersection of a cutting body with the tube surface, yielding a cut (penetration) contour (DD-Kontur).
Durchstecken (through-penetration) Durchstecken Tube machining case producing a through opening for another tube.
Ebener Schnitt (planar cut) Ebener Schnitt A planar cut of the tube.
Echo-Modus (echo mode) Echo-Modus A reversible XOR drawing mode for interactive rubber-band feedback.
Eckenbehandlung (corner treatment) Eckenbehandlung Corner treatment — loop-out, cooling dwell, rounding, radii or lead-in/out applied at contour/profile corners.
ecopy ecopy An MMK built-in command that assigns/expands a value into a variable (contrasted with copy).
Eingabefeld (input field) Eingabe-Button A data-entry widget with prompt, suffix, format, type and decimal-place attributes; validated by plausibility rules.
Einrichteplan (setup plan) Einrichteplan Operator document with sheet/part graphics and tool/technology lists accompanying the NC program (HTML/PDF).
Einsatz (insert) Einsatz Tube machining case where one tube is fitted into another.
Einstechen (piercing) Einstechen Initial beam penetration of the sheet before cutting; typed with its own parameters (LT_EINST_*).
Eintrag (entry) Eintrag A workbook item, typically a sheet, with processing state and repeat count (TcEintrag).
Einzelhub (single stroke) Einzelhub An individual punch stroke; its technology is carried in MI/CAPT files.
Einzelteil (single part) Einzelteil A single fabricated sheet-metal item extracted from a drawing and stored as a geometry file.
Einzugsradius (feed / insertion radius) Einzugsradius Feed/insertion radius at the die edge.
Entfolierung (foil removal) Entfolierung / Entfolieren Stripping protective-foil geometry from elements/contours.
Entladen (unloading) Entladen Programmed removal of good parts and scrap by holding devices, managed with pluggable strategies.
Entsorgungszone (disposal zone) Entsorgungszone Pallet/unit area for scrap and skeleton disposal.
FabConnector / PPS plugin PPS-Plugin A registry-discovered, licence-checked .NET assembly (implementing TiPlugin) that supplies orders and receives job-state feedback for TruTops Fab.
Falzung (hemming) Falzung A hemming bend (closed or nearly closed fold), with up/down variants and its own deduction factor.
Fangen (snapping) Fangen Rule-based attachment of a picked point to nearby geometry (what/how/where/radius).
Fase (chamfer) Fase A straight bevel created between two adjacent elements at a corner.
feld_umschalten feld umschalten MMK command that switches the active input field within a dialog.
Fertigteilunterstuetzung (finished-part support, FUS) Fertigteilunterstützung Movable support holding the cut-off finished tube section; modes none/preset/with-lift-lower/moving-along.
Fertigungsauftrag (production job) Fertigungsauftrag An NC program plus target count and technology data; an element of the production plan (NcListe).
FINDER Finder A scrollable list widget target (FINDER_1..FINDER_6) filled by a mini_sql query.
Flycut (fly-cut) Flycut Fly-cut positioning — moving between grid cuts without stopping, reducing non-productive time.
Fourierbeschreibung (Fourier description) Fourierbeschreibung Fourier description of a closed contour used to test similarity and derive relationship parameters (rotation, scale, translation).
Freibiegen (air bending) Freibiegen Air-bending forming method (part bridges the die opening without touching the die bottom).
Freistich (relief groove) Freistich A relief groove created at a corner/edge.
Frozen / off layer eingefrorener / ausgeschalteter Layer DXF layer states ignored by default during import.
Fuellkontur / Fuellmuster (fill contour / pattern) Füllkontur / Füllmuster A closed contour marked for fill and the fill pattern (hollow, solid, hatch, cross-hatch).
Füllteil (filler part) Füllteil A production order flagged as a filler part used to fill remaining sheet area during nesting.
Genauhalt (exact stop) Genauhalt A motion ramp where velocity is zero at both start and end of a path segment.
GEO / GEO_102 GEO TRUMPF native geometry file format (two versions) used as internal storage/exchange.
Gesenk / Unterwerkzeug (die / lower tool) Gesenk / Unterwerkzeug The lower press-brake tool (die) (WZG_GESENK).
Gesenkweite (die width) Gesenkweite The V-opening width of the die, quoted with or without the feed/insertion radius.
Gewindeformen (thread forming) Gewindeformen In-machine forming of a threaded/extruded feature using extrusion and forming tools.
Gewindeformer (thread former) Gewindeformer A tool forming/cutting a thread with pitch/ratio/direction, assigned to material and thickness (GEWINDEFORMER).
Gitterfertigung (grid production) Gitterfertigung Nesting that retains a supporting skeleton/grid between parts.
GMT GMT ToPs 1000 geometry format; the converter can stamp its drawing/part number.
Grafik-Button (canvas / draw button) Grafik-Button (Grafb) GRIT widget hosting the on-screen graphics canvas and its display context.
GRIT GRIT (Graphics Interactive Tool) The legacy C++ UI framework providing masks, buttons, menus, the MMK interpreter and interaction handling across all TruTops editions. See [[22 - FR - UI Framework, Dialogs & Interaction (GRIT)]].
GTS (common cut / cut simulation) GTS (Gemeinsame Trennschnitte) In nesting/punch, nesting parts to share separating cuts (common cut); in laser, also used loosely for graphical cut simulation. Exact acronym unconfirmed.
Gutteil (good part) Gutteil A finished usable part to be palletized.
H2O / Wasserstrahl (water-jet) Wasserstrahlschneiden Water-jet cutting variant present inside the laser module (WASSER01..05, control type c_H2o).
Hardcopy Hardcopy Raster screenshot of a screen region/viewport written to an image file (BMP/TIFF).
Huellkreisdurchmesser (envelope-circle diameter) Hüllkreisdurchmesser Envelope-circle diameter bounding a profile, used for guide/support sizing.
Innenkontur (inner contour) Innenkontur A hole/island in a part, usable for part-in-part filling.
ITM / SW06 (central tool management) Integrierte Werkzeugverwaltung Integrated/central networked tool management, connected via the SW06 business-model wrapper for live tool availability.
Kacheln (tile nesting) Kacheln Regular row/column matrix arrangement of a single part type.
Kassette (cassette) Kassette A tool-holder cassette (steel/RTC/size-5) (KASSETTE).
Kennzeichnen (marking / engraving) Kennzeichnen Non-cutting laser marking of text, labels and DataMatrix codes.
Kleinteile (small parts) Kleinteile Small cut parts ejected via flap/chute or suction to a sorting unit.
Klinkung (notch / corner relief) Klinkung A material cut-out at a corner/edge; in bending, a relief cut at bend-line intersections to avoid material collision during folding.
Kontur (contour) Kontur An ordered, connected chain of geometry elements; open or closed, outer or inner.
Konturaufbereitung (contour preparation) Konturaufbereitung Offset/equidistant-oriented geometry cleanup applied before writing certain formats.
Körnen (centre-punching / marking) Körnen A laser or punch step marking a point on the sheet.
Lagergut (stock item) Lagergut A storable sheet/remnant inventory item, a concrete physical sheet of a raw material (MAT_SHEET, keyed by MAT_LAGERGUTID); lockable when in use.
Langloch (oblong hole) Langloch An oblong/slotted-hole macro.
Lasertechnologietabelle (LTT) Lasertechnologietabelle Cutting technology table — machine-/material-/thickness-dependent parameter set for cutting, piercing and marking (LASERTECHNO).
Leerweg (idle stroke) Leerweg A non-cutting head move, e.g. lifting over a raised/formed feature.
Linienart / Linienfarbe (line style / colour) Linienart / Linienfarbe Line style and colour (index 0–15) classifying an element; serves as a layer surrogate (no named-layer object exists).
Lochgitter (hole grid) Lochgitter A 2D array pattern of holes.
Lochkreis (hole circle) Lochkreis A pattern of holes arranged on a circle (bolt-hole circle).
Lochreihe (hole row) Lochreihe A linear pattern of holes.
Maschinenschlüssel (machine key) Maschinenschlüssel The 4-part identity (name, type, control, control-version) uniquely selecting a machine + control (TcMaschinenSchluessel, PK of MASCHINE).
Maske (mask / dialog) Maske A GRIT screen form/dialog, the fundamental UI unit; stored as .gritx XML, .olb binary or .a26 ASCII.
Matrize (die) Matrize The lower cutting die opposite the punch (DIE, LASERMATRIZE).
Mehrfachnutzen (multiple-up, MFN) Mehrfachnutzen (MFN) A block of identical parts processed together to shorten the NC program and enable block-wise unloading.
MI (Macro Interchange) MI HP ME10 macro interchange CAD exchange format; TRUMPF's native versioned text geometry file (versions 2.21 and 2.4).
MI-Interpreter MI-Interpreter The reader/writer (tc_mi) for TRUMPF's native text geometry file format, versioned via MI_Version_Nr.
Microweld (micro-weld) Microweld A re-welded connection retaining a part after laser cutting.
Mikrosteg / Steg (micro-joint / bridge) Mikrosteg / Steg A small uncut bridge/web that keeps a cut part attached to the skeleton until removal (MAS_STEGE, STEG_TYP).
mini_sql mini_sql The SQL-like subset in MMK used to bind database rows into finder lists/fields (SELECT INTO) and write edits back (INSERT/UPDATE/DELETE).
MImpl / NImpl (managed / native impl.) Managed-/Native-Implementierung The Xidl-toolkit managed (.NET) and native (C++) implementation halves of an API.
MMK (interpreter) MMK-Interpreter The embedded lex/yacc scripting language run from mask/button CDATA that drives dialog behaviour, data binding and control flow.
Multitool (multi-tool) Multitool A multi-tool station holding 2–12 stamps selectable by index and rotation.
Musterteil (sample / master part) Musterteil A test part placed before quantity-driven nesting to validate the layout.
Nachschachteln (re-nesting) Nachschachteln Re-running nesting on selected or already-nested parts.
Nachsetzen (repositioning) Nachsetzen Automatic re-gripping/moving of the sheet so out-of-range areas become reachable, splitting a program into setups (Aufspannungen).
Nahtlage (weld-seam position) Nahtlage The weld-seam position of a welded tube, used to orient/reorder the contour.
NcLink NcLink External TRUMPF tool that sequences NC programs and formats the production plan for the machine control.
NC cycle (Zyklus) Zyklus Controller subroutine/macro text emitted for a machine function; standard (NC) and customer cycles (Kundenzyklen) both supported (NCZYKLEN).
NC generation (NC-Erzeugung) NC-Erzeugung Emission of an executable, controller-specific NC program from a finished CAM layout. See [[18 - FR - NC Generation & Motion Optimization]].
NC-Kopf-Tabellen (NC head tables) NC-Kopf-Tabellen Header/format masks (NC_KOPF_TABELLEN, AUS_FORMAT) used to render NC blocks per controller.
Nesting (Schachteln) Schachteln Automatic or interactive arrangement of parts onto sheets to maximise material use. See [[17 - FR - Nesting & Palletizing]].
Neuzeichnen (redraw) Neuzeichnen Repaint of the viewport contents, bracketed by start/end redraw and guarded by a redraw-in-progress flag.
Nibbeln (nibbling) Nibbeln Producing a contour by many overlapping strokes of a smaller tool; linear (nibb_lin) or circular (nibb_cir).
Nutgrundradius (groove-ground radius) Nutgrundradius Groove-ground radius of the die.
Oberfläche (surface) Oberfläche (Oberfl) The base "surface" class from which masks and popups derive.
Oberwerkzeug / Stempel (upper tool / punch) Oberwerkzeug / Stempel The upper press-brake tool (punch) (WZG_OW).
Öffnungswinkel (opening angle) Öffnungswinkel Opening angle of a bend tool (punch tip or die V).
OmAdapter OmAdapter Object-manager adapter facade abstracting file access over the local file system or a PDM vault via TiPdmFacet.
Palettierung (palletizing) Palettierung Arranging finished parts, scrap and skeleton onto pallets/stacks for unloading.
Plausi (plausibility validation) Plausibilität Input validation against interval, set, alphanumeric, constant or free-form rules.
Plotten (plotting) Plotten Output of a drawing to a pen plotter using HPGL/HPGL2.
Portierung (porting) Portierung Porting/conversion of database content, notably between metric and inch representations, logged in Logging.PortierungLog.
Positionierwege (positioning paths) Positionierwege Rapid/repositioning traverse moves of the machine head; a toggleable display class.
Pratze (clamp) Pratze A sheet-holding clamp on the machine table; clamp positions create dead zones avoided by processing.
Prägen (coining) Prägen Coining bend method — pressing the material fully into the die for a precise angle.
Produktionsplan (production plan) Produktionsplan The sequenced set of production jobs sent to the machine control, generated by NcLink.
Produktionsauftrag / ProdOrder (production order) Produktionsauftrag An order imported from a PPS/MES system (part, material, quantity, due date, machine, rotatability) fed into nesting.
Profil (profile / cross-section) Profil / Querschnitt A bent cross-section (bending) or tube section shape: round, rectangular, flat-oval, custom, open L/U/C or flat material.
Programmierprojekt (programming project, PPJ) Programmierprojekt A workbook binding machine, material, sheets, parts and tools for one order; persisted as versioned .ppj XML.
Prozessoption (process option) Prozessoption A named strategy bundle for part support/separation (falling/tilting/hooking/stable), APS mode and micro-joint type (PROZESSOPTIONEN).
Punkt (point) Punkt A coordinate node: element endpoint, catch/snap point or construction point.
Raum (3D space) Raum The 3D "space" representation of the tube (as opposed to the unrolled 2D view).
Regelwerk (rule set) Regelwerk System configuration variables (REGEL_ALLG) and/or the machine/technology assignment rules governing automatic tool/technology assignment.
Reproduktion (reproduction) Reproduktion Headless batch re-nesting of parts (tc_reproduction) for regression or server-side use.
Restgitter (residual grid / skeleton) Restgitter The remaining skeleton lattice of a cut sheet; a toggleable display class.
Reststreifen (residual strip) Reststreifen A remnant skeleton strip cut into disposable pieces.
Resttafel (remnant sheet / offcut) Resttafel A usable leftover sheet area saved as *.trg geometry for reuse (also created by a laser dividing cut).
RMT RMT Raw-material tube file carrying material, wall thickness and section dimensions.
Rohr (tube) Rohr Tube/pipe; the longitudinal workpiece machined on a rotary laser. See [[15 - FR - Tube & Profile Machining (ToPs 400)]].
Rohrende (tube end) Rohrende The tube end; site of end/miter cuts (left/right).
Rohrfuehrung (tube guide) Rohrführung A tube-guide element on the machine.
Rohrfutter (chuck) Rohrfutter The chuck that clamps and rotates the tube.
Rohling (blank / sheet entry) Rohling A blank/sheet entry within an order (TcPpjRohling), carrying repeat count, state and TAF/TMT/NC references.
Rohroptimierer (tube optimizer) Rohroptimierer Configuration controlling machining sequence over the unrolled tube (sectors, directions, strategies, chuck area).
ROT ROT Stream/file describing the tube's 3D surface, triangulated for display.
RPF RPF Profile geometry file describing an open or closed cross-section.
Rundung (fillet) Rundung A tangential arc created between two adjacent elements at a corner.
Sauger (suction cup) Sauger A suction cup (carry/peel/pivot/coupling/programmable) — a holding device on a lift frame for part unloading.
Schachtelauftrag (nesting order / job) Schachtelauftrag An order created by the nester and stored in a job file; the source of a programming project, and the nest job + result exchanged with Fab.
Schaltfunktion (switching function / cycle) Schaltfunktion Auxiliary machine functions (lubrication, suction, flap, punch-head position, tool-change position, calibration, customer cycle).
Schildchen-Attribut (bend tag) Schildchen-Attribut A free-text tag/label attribute attached to a bend line for annotation.
Schraffur (hatch) Schraffur A fill pattern inside a closed contour.
Senkrechtschnitt (perpendicular cut) Senkrechtschnitt A perpendicular cut of the tube.
Shop-floor programming (SFP) Werkstatt-Programmierung Headless programming of a laser job (convert, nest, GMT, NC list) via the TruTopsLaser C DLL, without the interactive editor.
Skalierungsfaktor (scale factor) Skalierungsfaktor Scale factor between world units and device/paper units for print/plot output.
SortMaster SortMaster TRUMPF automated sorting system distributing unloaded parts to defined pallet compartments (SORT_FACH/SORT_PALETTE).
Spalten (columns) Spalten Data-dictionary column definitions (DATADICT_SPALTEN): type, units, min/max, regex and uniqueness per column.
Sperren (locking) gesperrt / Lockstate Locking of a stock/nesting record (VAR_EINTRAG_GESPERRT, MAT_LOCKSTATE) to prevent conflicting use.
Stack (Stapel) Stapel A pile of stacked goods on a pallet built by palletizing.
Stack good (Stapelgut) Stapelgut An item to be stacked: good part, scrap or residual grid.
Stack variable Stack-Variable A named value on the MMK interpreter variable stack — the data-exchange channel between scripts, masks and the ASM.
Stanzen (punching) Stanzen Producing geometry by discrete tool strokes (hits) on a punch press. See [[13 - FR - Punching (ToPs 300)]].
Startecke (start corner) Startecke The corner of the sheet at which meander/standard processing begins.
Steg / Stegbelegung (bridge / web) Steg / Stegbelegung An uncut web (and its named layout) in scrap-dicing/grid patterns; also the minimum spacing kept between adjacent nested parts.
Stegfrei (gridless) Stegfrei Nesting without micro-joint webs, common for laser cutting.
Stempel (stamp / punch) Stempel A single punching element; multi-tools hold several.
Steuerung (controller) Steuerung The machine control (e.g. Sinumerik 840D) identified with a version; part of the machine key.
Steuerungsversion (control version) Steuerungsversion Control firmware version; gates NC output and feature availability via STEUERUNGSVERSIONEN.
TAF / TMT TAF / TMT Sheet geometry file (TAF) versus sheet geometry with machining (TMT); their consistency/currency is tracked per sheet.
TAF (archive/table format) TAF TRUMPF archive/table format accepted as a converter input (needs a TAF→DXF special export path).
Tafel (sheet) Tafel The raw stock or nested sheet onto which parts are nested; the physical metal sheet.
Tafelinfo (sheet info) Tafelinfo A sheet-info annotation block for a nest/sheet.
Tafelschnitt (sheet dividing cut) Tafelschnitt A separating cut that divides the raw sheet or detaches a remainder sheet.
Teil (part) Teil A logically grouped set of contours/elements within a drawing; the fabricated sheet-metal item.
Teilegruppe (part group) Teilegruppe A part group enabling common cut, where adjacent parts share a single cutting line.
Teileuebersicht / Mustertafel (part overview / master sheet) Teileübersicht / Mustertafel A grid of representative parts machined once and propagated to identical parts.
Teil-in-Teil (part-in-part) Teil-in-Teil A situation where a part is nested inside a cut-out of another part; tracked per sheet.
TEO TEO Tube-exchange object file of grouped contours passed via PDM.
Termin (due date) Termin The date by which a part must be finished (Nest.TEILE_ERFASSEN.TEIL_TERMIN).
ToPs module ToPs-Modul A Python module (import ToPs) exposing application services — environment, DB texts, language, stack vars, console, file/password checks, hooks.
TraceMode / trace file Trace-Modus / Trace-Datei (.taf) A mode recording the interactive command trace so a session can be reproduced (feeds reproduction/regression).
TUBETECH TUBETECH Tube technology master record keyed on cross-section, material and dimensions.
TwinLine / 2-Kopf (two-head) TwinLine / Zweikopfbearbeitung Multi-head processing on machines with two cutting heads, programmed with a head offset and active-head selection.
Überfahrbereich (overrun / traverse area) Überfahrbereich Region the tool head may traverse beyond the work area.
Unterwerkzeug / Gesenk (lower tool / die) Unterwerkzeug / Gesenk The lower press-brake tool (die).
Variante (parametric variant) Variante Named variables, references, changes and loops producing geometry variations, evaluated via embedded Python.
Vektorisierung (vectorization) Vektorisierung Conversion of a raster image into vector geometry, performed by the external ToPsVectorize tool.
Verschnitt (waste / offcut) Verschnitt Unusable scrap material of a nested layout.
Verwaltung (management) Verwaltung Management; tc_verw provides file-attribute reading (TcGeoInfos) and part-property checking.
Viewport (Zeichenfenster) Zeichenfenster / Viewport An opaque drawing surface (TC_Viewport) with its own world window, attributes and device mapping.
Walzrichtung (grain / rolling direction) Walzrichtung Material-texture axis constraining part orientation during nesting.
Wandstaerke (wall thickness) Wandstärke Wall thickness of the tube/profile.
Werkstoff (material) Werkstoff A material grade with physical/technological properties and international designations (MAT_MATERIAL).
Werkstoffgruppe (material group) Werkstoffgruppe A grouping of materials with abbreviation and price-per-kg for costing (MAT_GRP).
Werkzeug (tool) Werkzeug A punch tool, laser head or die used to machine the sheet.
Werkzeugliste (tool list) Werkzeugliste A named collection of tools (e.g. a machine's loaded tool set / magazine).
Wiederholzahl / Sollzahl (repeat / target count) Wiederholzahl / Sollzahl How often a sheet or NC program is to be produced.
Xidl remote factory Remote-Factory An Xidl-toolkit object registry addressed by URI + plugin name for cross-process / managed access to the per-edition component API.
Zerstanzen (destruction punching) Zerstanzen Breaking scrap into small removable pieces for disposal.
Zwangsfolge (forced sequence) Zwangsfolge A user-mandated processing order that optimization must not reorder.
