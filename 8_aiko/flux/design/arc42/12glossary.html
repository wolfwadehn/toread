12 — Glossary

Architecture-level glossary. The full domain glossary (CAM vocabulary plus Flux-internal terms) lives in Onboarding chapter 08; this page lists the architectural terms only, with cross-references where useful.

A

ADR — Architecture Decision Record A short, structured note recording a single architectural decision, its context, and consequences. Section 9 of this Arc42 set is the ADR list.

Aegis The Metamation licensing back-end, used for the Flux flavor. Online soft-locking. Package: Aegis.API.

Arc42 The architecture-documentation template this set follows. https://arc42.org/

Au / Gold Compact binary serialization format used internally by Flux for runtime state (Part, BendTech, BendOp, …). Documented in Notes\Dev\1003.AuGoldEncoding.ftx.

B

BA "Boilerplate Assist" — a static helper class in Flux.Base. The most-used member is BA.Set<T>(ref field, value), which combines equality check + change notification + undo registration. See ADR-005 enabler patterns.

BCell The bend-cell automation domain. Robot, gripper, suction cups, regrip stations. Lives at BendTech.Cell. See Onboarding chapter 02.1.

C

Composite glob The synthesized controller that appears when multiple objects of the same domain type are selected. Routes commands to all members in a single undo unit. ADR-010.

Curl Lisp-flavored text serialization format used for human-curated data: machines, tool catalogs, settings profiles. Documented in Notes\Tech\2007.CurlFiles.ftx.

D

Dev (flavor) The developer build. Whitelisted machines only. No installer.

Dump The text-output method on every tech (BendTech.Dump, BendSetup.Dump, BCellTech.Dump). Its output is the test contract — golden .txt files compared by Flit. ADR-008.

E

Engine (flavor) Headless Flux variant embedded in Trumpf Praxis. No UI. Strictest discipline driver.

EResult Standard return enum for fallible operations. ADR via convention: predictable failures use EResult, invariant violations use exceptions.

F

Feature bit A flag controlling per-flavor feature availability (Bend, Laser, Punch, UI, Trumpf, …). Documented in Notes\Tech\2013.FluxFlavors.ftx lines 38–57.

Flavor A build variant — one of the ten EFlavor values: Dev, Flux, Trumpf, Boost, Engine, ShopFloor, Lantek, Viewer, SDK, OneCore. Selected at runtime via the Flux.flavor text file. B23, Fold (TecZoneFold) and Tech are installer variants on top of Trumpf. Each flavor pairs with a specific licensing back-end (see §7.4). ADR-003.

Flit The custom test framework Flux uses. [TestFixture] / [Test] attributes. Namespace Flit.

FX (helper class) The static helper class in Flux.Base: logging (FX.Out), test helpers (FX.LoadTestPart), permits (FX.Permits), persistent notes (FX.Notes), etc.

FX file The native Flux save format: zip of Curl + Au + thumbnail. (Not to be confused with the helper class.)

G

GElement Abstract description of a glob property (label, value editor, validation). Translated to WPF by PanelMaker.

Glob Controller object wrapping one domain object for UI editing. Decorated with [Glob (Draw=true, Mouse=EMouse.LDown)]. Composite globs handle multi-selection.

H

Hex (language) Originally planned post-processor language (Note 2004, 2016). Superseded by C# writers in Src\API\Bend\Post\. ADR-009. The Flux.Hex namespace and Src\Base\HexLib.cs survived but no longer host a Hex interpreter — today they provide the small JDoc / XDoc document-builder utilities used by config-sync, TSO reports, DLD export, and the bend optimiser. Live infrastructure under a legacy name, not dead code.

HOOPS TechSoft's 3D library used for CAD-format import. Wrapped by Flux.Hula64.dll. Version pinned to 25.4.

Hub Static class with typed Func<> / Action<> slots, filled by App at startup, invoked by Core/UI null-safely. Replaces the legacy Hub whiteboard. ADR-002.

Hub whiteboard The legacy untyped object-bag pattern that the typed Hub replaces. Anti-pattern; do not introduce.

I

ISheafSite Marker interface for objects whose settings cascade up to a parent. Defines SHName, SHDict, SHParent. ADR-006.

L

Lantek The Lantek-branded OEM distribution of Flux (EFlavor.Lantek, "Lantek Bend"). Uses its own licensing stack — Lantek.Key SDK + signed LantekLic XML (RSA-2048 / SHA-256) + remote validator FLConnect.exe. Implementation: LantekLock in Src\Core\Permit.cs:1274. Data root: <LantekInstallDir>\Data\.

LantekLic The signed XML license file the Lantek flavor reads at startup. Contains an enumerated list of permitted machines and a detached RSA-2048 / SHA-256 / PKCS#1 signature; tampering invalidates the file (errors 8579/8580). Read by LantekLock.GetLantekLicContent (Permit.cs:1374).

Lux The OpenGL-based rendering layer in Flux.Base. Lux.DrawMesh, Lux.Layer, Lux.Mood, LuxShading, Lux.Redraw.

M

Make The conventional name for static factory methods (BendTech.Make, Machine.Get, BendMachine.Get). Constructor is private; factory enforces invariants. ADR-005.

Mark The CLI tool used to upload Markdown files to Confluence. Used by sync.ps1. Not a Flux runtime artifact.

P

Part Top-level job aggregate. One per opened document. Implements ISheafSite, INotifyPropChanged. Holds Model, Dwg, plus optional tech projections (BendTech, FoldTech, CutTech, …). ADR-004.

[PostLoad] Attribute marking a method that runs after Au-deserialization. Used for forward migration of older shapes via AuType.ObjVersion < N checks. ADR-007.

Praxis Internal Trumpf system that embeds Flux as the Engine flavor.

[PStatic] / pstatic.curl "Persistent static" — attribute on a static field that should round-trip across application invocations. At startup, App registers participating assemblies via PStaticAttribute.AddAssembly, then PStaticAttribute.Load reads recent:pstatic.curl and hydrates marked statics by reflection (<TypeName>.<FieldName> keys, AuCurl-serialised values). On exit, Save writes the same file. Used for UI-state crumbs that don't belong in Sheaf (recent-files list ALib.sRecentFiles, file-dialog last-used paths, panel-splitter positions, expander open/close state, main-window geometry). Distinct from Sheaf (typed, schema-driven, cascaded settings) and FX.Notes (loose key/value dictionary). Implementation: Src\Base\BClasses.cs:405–:470; lifecycle hook in Src\App\App.xaml.cs:123, 193-198.

S

Sheaf The cascaded settings dictionary. Every ISheafSite has its own dict and a parent. ADR-006.

T

Tech (projection) A domain projection of a Part — BendTech, FoldTech, FlatTech, BCellTech, LayoutTech. Each is independent. ADR-004.

TLM / TLE Trumpf License Manager (Sentinel) / Trumpf License Expert (WIBU). Two licensing back-ends used for different Trumpf flavors.

V

VModel Base class for view-models. Lives next to its model in Flux.Core. ADR-001 (model and view in same DLL).

W

Wad / Flux.wad ZIP of read-only resources (shaders, metadata, fonts). On dev machines, FLUXWAD=X:\Wad (loose folder); on installs, Flux.wad next to Flux.exe.

WIBU The Trumpf License Expert (TLE) back-end. USB or soft-locked. Used for Trumpf and Boost flavors.
