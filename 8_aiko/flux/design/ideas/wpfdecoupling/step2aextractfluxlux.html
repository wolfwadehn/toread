Step2aExtractFluxLux

product: flux org: metamation tags: [metamation, knowledge-base, flux, refactor, wpf, architecture, spec] type: spec project: Flux updated: 2026-07-14

Part of the [[WPF Decoupling]] spec · Step 2a · [[Step 2 - Split into Decoupled Assemblies|Step 2 overview]] · uses [[Reference - Seams and Service Interfaces]]

7. Detailed change spec — Flux.Lux (extract the engine)

Files to move (~5,000 LOC), all currently namespace Flux/Flux.OpenGL/Flux.Internal in Base/:

Base/Lux/: Lux.cs, LuxDraw.cs, LuxUtil.cs, LuxPanel.cs, Scene.cs, Layers.cs, VModel.cs, VModelImp.cs. Base/GL/: GL.cs, GLArray.cs, GLBinding.cs, GLMouse.cs, GLProgram.cs. Plus the GL-relevant subset of Base/Native.cs (SafeNativeMethods P/Invoke). Not Base/Pline/GLPlineOps.cs — despite the name it is pure geometry (Boolean, Convexifier), no GL/WPF, and stays in Base.

7.1 Per-file verdict

File Verdict WPF work before it can move to the net10.0 Flux.Lux
Scene.cs, Layers.cs, VModel.cs, VModelImp.cs → Flux.Lux none — already WPF-free
GLBinding.cs, GLProgram.cs → Flux.Lux none (GLProgram depends on BA.OpenRead("wad:…") for shaders — keep resource loader)
Lux.cs → Flux.Lux replace DispatcherTimer sTimer (:293)→IUiTimer; CreatePanel():UserControl (:29)→ILuxHost (WPF overload in Flux.Lux.Wpf); LuxPanel.It→Lux.Host
LuxDraw.cs → Flux.Lux DrawDecal (:462-468) decodes an image via BitmapImage/FormatConvertedBitmap/PixelFormats.Bgra32 → replace with WPF-free decoder (Skia/ImageSharp) → same byte[] to GL.TexImage2D
LuxUtil.cs → Flux.Lux SceneManipulator.OnMouse calls Keyboard.IsKeyDown(Key.*) (:62-65) → route through IInputState
GL.cs → Flux.Lux static Dispatcher Dispatcher (:67-71, captured :373) → SynchronizationContext in MarkUIThread
GLArray.cs → Flux.Lux GL.Dispatcher.Invoke(Release) (:153) → sync.Post(_=>Release(),null)
GLMouse.cs split dispatch core (EMouse, TrackData) → Flux.Lux with WPF-free Post(...) entry; WinForms event wiring + LuxPanel.It.PointToScreen/ActualWidth/ActualHeight (:225-230) → Flux.Lux.Wpf via ILuxHost
LuxPanel.cs → Flux.Lux.Wpf the whole WPF UserControl (:27) + WinForms LuxSurface (:215). Extract the WPF-free FBO logic (BeginRender/EndRender/Size, :80-151, already byte[]/glReadPixels) into a core IRenderTarget impl; keep context creation (wglCreateContext, :215-323) here

7.2 Flux.OpenGL / Flux.Internal

Both are Base-internal namespaces, not projects. Flux.OpenGL lives only in the four GL files → moves wholesale. Flux.Internal is spread across ~40 files repo-wide; carve out only its Lux-owned members (LuxSurface, LuxAnimateProp<T>, ObjXfm, SGNode) — the namespace itself stays shared.

7.3 Base geometry the engine needs (stays in headless Flux.Base)

All WPF-free, referenced heavily by Lux (usage counts): Pline/PlineSet (84), Point2/3/2f (63/24/15), Matrix3 (33), Color32 (32), Bound2/3 (28/6), Vector2/3/3f/4f (19/5/4/14), NPoint2 (17), Figure (16), Mesh3 (7), Line3 (4), CoordSystem/Quaternion4 (4/3), plus INotifyPropChanged, EModifiers, BHub selection API, BA.OpenRead resource loader. Flux.Lux references a headless Base.

7.4 LuxPanel consumers to rewire (to ILuxHost)

Engine-internal (move with core): Lux.cs (LuxPanel.It/.Size/.Redraw/BeginRender/EndRender ×many), GLMouse.cs:225-230. Host-creation call sites (become Flux.Lux.Wpf.CreatePanel() or a headless OffscreenHost): Core/CmdProcess.cs:272,445,1176,1612, Core/Fold/Ops/FParamPart.cs:26, API/Bend/BendBoost.cs:181,504, API/Cut/Layout.cs:249,262, API/Dwg/Drawing.cs:56, API/Lux/Lux.cs:298-307 (HiddenLuxPanel), App/MainWindow.xaml.cs:57, Console/*Viewer.cs. .Surface cursor/size sites (→ ILuxHost.Cursor/ClientSize): UI/Dwg/Measure2D.cs:24,63, UI/Misc/Widget.cs:133, UI/Misc/WPFUtil.cs:38-50, UI/Job/JobBar.xaml.cs:1820, UI/Dwg/Widget/TrimExtend.cs:455.

7.5 The ILuxHost/IRenderTarget seam (and the web hook)

LuxPanel.It (singleton) is the entire surface the engine asks of the host — see interface in §6. Replace the static LuxPanel.It with an injected Lux.Host. Ship two implementations:

  • Flux.Lux.Wpf.WpfLuxHost — the interactive UserControl + WinForms GL surface (today's LuxPanel).
  • Flux.Lux.OffscreenHost : IRenderTarget — a message-only HWND + FBO, no Window, so headless RenderToFigure works (thumbnails/reports). This is the seam where, for the web goal, an ISceneEmitter later replaces GL entirely: EndRender returns scene deltas instead of pixels.

7.6 The blocking prerequisite — BA (Base/Base.cs)

The engine calls the app-wide BA helper: BA.PumpMessages ×2, BA.Post ×2, BA.MakeTimer ×2, BA.After, BA.MainWin, BA.DPIScale ×16, plus WPF-free BA.OpenRead/Clr/env. Flux.Lux cannot be WPF-free until BA's scheduling/timer/pump/MainWin members are abstracted (§8.3). Do the BA seam first, then extract Lux against it.
