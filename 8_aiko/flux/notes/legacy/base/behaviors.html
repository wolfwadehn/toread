Flux.Base : WPF Behaviors

[!info]- Revision history

Rev Date Author Note
V1 2018-05-26 AV

Flux.Base contains a number of pre-packaged WPF Behaviors that can be attached to a FrameworkElement. These are fairly self-contained modular units of functionality, and usually you have to do very little after attaching the behavior. Some behaviors can be attached only to a Window, while others can be attached to any FrameworkElement (look at the parameter in the behavior's constructor).

CloseOnClickOutside

Attach this behavior to a Window to have it close automatically when the user clicks anywhere outside the Window. The code to attach this behavior often goes in the Window's constructor, and could look as simple as this.

class SomWindow : Window {
   public SomeWindow () {
      ...
      new CloseOnClickOutside (this);
   }
}

KeepWithinOwner

Attach this behavior to a Window, to ensure that it cannot be dragged outside its Owner window. For example, in Flux, we use this to constrain the ModeBar (the Window that displays the numerous drawing command icons) from being dragged outside its owner drawing panel.

LongClick

This behavior is used to add long-click support to a FrameworkElement. When the mouse is clicked, this starts a timer and waits for a pre-defined time interval. If the mouse is still down (has not yet been released) when the timer has elapsed, this raises a long-click event (by calling the provided delegate). Also, if the mouse moves by more than a specific number of pixels, it fires the event (these are typically used to start a drag operation).

If the mouse is released before this timer has elapsed, and before the user has dragged it any significant distance, this is just a short-click, and the provided shortClick delegate is called. The element itself is passed as parameter to these delegates. For example, in the code below, a long-click starts dragging a bend, while a short click just selects it for editing.

new LongClick (elem, OnDragBend, OnSelectBend);
|
void OnDragBend (object elem) {
   int nBend = (int)(((Border)elem).Tag);
   StartDraggingBend (nBend);
}
|
void OnSelectBend (object elem) {
   int nBend = (int)(((Border)elem).Tag);
   SwitchToBend (nBend);
}

MouseDragger

The MouseDragger class is base-class for all click-drag-release behaviors. Unlike many of the other behaviors, this is an abstract class and must be derived from before it can be used. In the derived class, the Action method is overridden, and the MouseDragger will call this repeatedly during the drag lifecycle. The meaning of the EAct parameter to this method is as follows:

EAct Meaning
Start The mouse-drag loop is starting (user just started dragging)
Move Mouse has moved to a new position
Finish Mouse-drag action finished (user has released the mouse button)
Cancel Mouse-drag operation got cancelled (element lost focus, or Escape key was pressed)

During this drag operation, there are a few locations (properties of the MouseDragger object) that can be used in the derived classes to implement the actual drag behavior. All of these are in WPF coordinates, relative to the framework element used to instantiate the mouse-dragger.

Property Meaning
Anchor The anchor point is where the mouse was originally clicked (this never changes)
Pt The current position of the mouse
PtPrev The previous position of the mouse

This means that the vector Pt-Anchor is the overall drag vector, and Pt-PtPrev is the incremental drag vector (between two successive calls to Action). A complete drag cycle is typically composed of one Start, multiple calls to Move and a final call to Finish (or with a final call to Cancel, if the user cancels the drag).

Note: At any point during this, the derived class can set the Abort property to true, to request a programmatic termination of the drag operation.

MouseRepeater

This repeats an action as long as a mouse button is held down on the element. The repeat rate is determined by the standard keyboard-repeat rate, and accelerates as the mouse is held down for a long time.

new MouseRepeater (upButton, () => Gauge.Height++);
new MouseRepeater (downButton, () => Gauge.Height--);

Resizer8Way

This behavior allows re-sizing a window by clicking near an edge and dragging. Normally, using a thick-frame for a Window allows it to be resized. However, you can also just attach this behavior to any Window, and obtain the same behavior.

When the mouse is moved close to the edges, the cursor changes to the appropriate resize arrow. When the user clicks and starts dragging, the window is resized appropriately.

WindowPosMemo

Attach this behavior to this window, and the Window's size (and optionally position) are remembered across sessions. This works in conjunction with the PStatic mechanism, and you need to load/save the PStatic contents when your application starts and shuts down. The key you pass into this constructor must be unique within your application, since this is used as a key by which this window's size is serialized.

class SomeWindow : Window {
   public SomeWindow () {
      ...
      new WindowPosMemo (this, "SheafEditor", true);
   }
}
