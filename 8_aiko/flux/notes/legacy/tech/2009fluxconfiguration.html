2009 ◉ Flux Configurations

[!info]- Revision history

Rev Date Author Note
V1 2016-01-29 AV

Flux is compiled in several different flavors. There is the canonical Flux with Metamation branding, and some variants of Flux with Trumpf branding. This document explains the rules Flux follows to locate the various files it needs at runtime.

Flux with Metamation branding

Flux with Metamation branding is installed in C:\Flux by default, but can be installed in any location that the user chooses at install time. Thus, multiple different versions of Flux can be installed on the same computer. Assuming Flux is installed in the default location:

Folder Contents
Flux\Bin Program files (flux.exe, flux.wad)
Flux\Bin\hoops Sub-folder contains the HOOPS import libraries
Flux\Data\Archive Catalogs for folding tools (later, will contain other catalogs, and refrence information)
Flux\Data\Machine Folder for all machine data. Each machine is stored in a subfolder inside this
Flux\Data\System Global program settings, material tables
Flux\Doc Program manuals and other documentation
Flux\Output Target folder for NC code output � can be altered by the user
Flux\Samples Sample files for the Flux installation

Flux with Trumpf branding

Here are the various folders used for installation, along with their contents:

Folder Contents
Program Files\Trumpf\Flux Installation folder, which contains just these:
Flux.exe - the executable
Flux.wad - resource file for Flux that contains icons, translation tables, 'factory default' settings
Program Files\Trumpf\Flux\hoops Sub-folder of install folder, containing the HOOPS libraries
ProgramData\Trumpf\Flux\Archive Catalogs of all folding tools (ENW, ZBW, main blades etc)
ProgramData\Trumpf\Flux\Machine Folder that contains all machine data. Each machine is stored in a sub-folder of this, like Machine\110001 etc
ProgramData\Trumpf\Flux\System Common system information, including material tables, bending allowance tables, global program settings
ProgramData\Trumpf\Flux\Samples Sample files for Flux installation
Program Files\Trumpf\Flux\Documentation Program manuals and other documentation
ProgramData\Trumpf\Flux\Output NC code output folder (this can be reconfigured by the user)

Note: This installation locations for this flavor are hard-coded. Multiple versions of Flux cannot be installed at the same time, and any installation overwrites a previous version.

Flux - B23 Edition

There is a special B23 edition of Flux that is intended to be used only on the B23 controller. This is different from the Flux with Trumpf branding in some important ways:

  • This is a 'Bend only' version of Flux. Other technologies like Fold, Laser, Punch etc are not available in this version, and they do not show up in the workflow panels.
  • When we are in the bending view, clicking the inventory button on the left brings up the display of the Preferred tools for that machine. There is no choice menu before that, and the user is not allowed to edit the global tool inventory.
  • The toggle-fullscreen button is not displayed on the top right. And, the F11 key does not work to toggle to full-screen mode.
  • The Trumpf logo is displayed at the top left, and the product is now called TecZone Bend.
  • The bend deduction, K-factor and bend allowance (flat-length) are displayed in bend lines in 2D and 3D. The K-Factor is not displayed in the bend technology view, only deduction and bend allowance are displayed.
  • It is possible to start Flux on a specified monitor by using a command line like flux -monitor=1 (the monitors are numbered starting from 0).
  • The fonts are changed to Segoe UI, Segoe UI Semibold, Consolas as used in the Touchpoint UI.
  • The Info button on the left command bar is removed, because it becomes too easy to activate it by mistake on the touch-screen monitor.
  • You cannot change the bend machine by clicking on the Bend machine name, or in the Workflow panel - this edition of Flux is designed for use with just one machine (the one initialized from MachineConfig.xml, as explained below).

Initialization process

When Flux/B23 starts for the first time, it is initialized with some machine settings to customize itself for the correct machine and with the correct options. This is done in the following way:

  • Flux determines if the machine initialization has been done already by checking the *X:\Data\Recent\notes.ini( file. If the file does not contain the following entry, it means this special B23 machine-initialzation has not yet been done:
    [Basic]
    B23MCinit=1
  • If the initialzation has not yet been done, Flux loads the C:\MMI\LocalSettings\MachineConfig.xml file and parses it to get the machine information (see Case 10957 for details). Based on this file, it selects the correct machine ID from the list of B23 machines.
